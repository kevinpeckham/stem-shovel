# Set lists

A **set list** is what you are going to play, in order: the songs for a show, the running order of a practice, the acoustic set you keep coming back to. Set lists belong to the account, so every member sees them. Find them in the **Manage** menu at the top, with Shows and Practices.

## Writing one

Press **New set list** on the Set lists page, give it a title ("Spring tour", "Tuesday rehearsal") and it opens for editing. Add rows two ways:

- **A song from your catalog.** Start typing a title in the **Add a song** box and pick it. The row is tied to the song, so the show view can open its chart and lyrics, and it follows the song's title if that changes. Type your own title into the row ("Interbellum (acoustic)", "Medley: Clocks / Interbellum") and the set list shows that instead; clear it to follow the song again. The song itself stays named under the row.
- **Anything else.** Type a title in **Add a line** for a cover that is not in Stem Shovel, a "break", "tune down" or "encore".
- **A whole list at once.** Press **Paste a list** and paste the set from your notes, one song per line. Numbering and bullets are ignored. A line that matches one of your songs by title becomes that song's row (a trailing "(acoustic)" or "– key of D" does not get in the way), and every other line stays as text, so a list of covers works too.

Every row has a **note** for the night: the key you play it in tonight, who counts in, a segue into the next song. Drag the handle at the left of a row to reorder, or use the arrow buttons. The **Notes** box above the rows is for the plan as a whole: tunings, who brings what, what the venue said.

A show with two sets is two set lists ("Set 1", "Set 2"); keeping each set its own list is what lets you reuse one. **Duplicate** on a set list's menu makes a copy to change.

## On stage

**Show view** is the set list the way you want it on a phone taped to the floor: big type, high contrast, one row per song with its note, nothing else. The screen stays awake while it is open. Tap a song to see its chart or lyrics right there; tap again to get back to the list.

To get it onto everyone's phones, make a **viewing link** on the set list's page (the same links songs and sessions have) and text it out: the link opens the show view without signing in, and nothing else of the account. Revoke it when the night is over, or give it an expiry when you make it. The show view prints cleanly if paper is more your band's speed.

## Keeping them

The Set lists page lists every set list of the account, last changed first, with a search by title. Your dashboard has a **Your Set Lists** section with the newest across your accounts, and a pin button on each row to keep one at the top. Deleting a set list removes its rows and its viewing links; deleting a song keeps the song's row in every set list as plain text with the title it had.
